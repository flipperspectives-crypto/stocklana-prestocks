# Pages demo checklist (Stocklana)

**Live URL:** https://flipperspectives-crypto.github.io/stocklana-prestocks/  
**Hard refresh** if you see a stale build (Cmd/Ctrl+Shift+R).

## Before record

- [ ] Open Pages URL on desktop (and optionally phone)
- [ ] Confirm status shows **Live · N tokens** (not Failed)
- [ ] Confirm **Agent briefing** shows biggest premium + biggest discount
- [ ] Confirm cards show Mark, Token, premium/discount badge, Solscan mint
- [ ] Confirm footer Havana timestamp updates after Refresh

## Record script (~2–3 min)

1. **0:00–0:20** — Title: “PreStocks Board for Stocklana — Best Use of PreStocks. Free API, $0 capital.”
2. **0:20–0:50** — Show live board loading from prestocks.com/api/prestocks (no login).
3. **0:50–1:20** — Explain Mark vs Token vs premium/discount formula on one card.
4. **1:20–1:50** — Point at Agent briefing outliers; click Refresh; note Havana clock.
5. **1:50–2:20** — Open a Solscan mint link; return; mention GitHub + Pages URLs.
6. **2:20–2:45** — Close: “Browser-only PreStocks research surface — submit as Best Use of PreStocks.”

## Screenshot stills (optional for submit)

1. Full board with briefing visible  
2. One outlier card zoomed (e.g. large premium or discount)

- Don’t claim trading / custody / KYC features
