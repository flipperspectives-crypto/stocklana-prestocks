## One-liner (≤140 chars)

## Short description (submit form)

PreStocks Board shows every PreStocks token’s private-company **mark** next to the on-chain **token** price and the live **premium/discount** gap. Built for Stocklana’s Best Use of PreStocks track with zero paid infra: static Vite app on GitHub Pages, `fetch` to the free PreStocks API, Solscan mint links, Havana-time updates, and an agent briefing strip that surfaces the biggest premium and discount outliers first.

## Longer pitch (optional)

Tokenized pre-IPO stocks already trade on Solana, but marks and token prices diverge — and most UIs hide that gap. PreStocks Board makes the gap the product: sort by absolute premium/discount, mobile-ok cards, free public API only (no key, no wallet, no RPC). Judges can open the Pages URL and verify live data in under a minute. $0 capital path matches how Lauren ships agent infra: public demos first, paid rails later.
